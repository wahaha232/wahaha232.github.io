Play Free Online · 2048 Number Puzzle

Join the tiles to reach 2048!
Score: 0

Use the arrow keys or WASD to slide all tiles, or swipe on a touch screen. Tiles with the same number merge into one when they collide.

How to play 2048

  • Every move slides all tiles as far as possible in one direction. A new 2 or 4 appears after each move.
  • When two tiles with the same number touch, they merge into one tile with double the value.
  • A tile can only merge once per move, so a row of four 2s becomes two 4s (not one 8) in a single move.
  • Your score increases by the value of every tile you create by merging.
  • The goal is to build a tile with the number 2048. Keep going afterwards for a higher score if you can.
  • The game ends when the board is full and no adjacent tiles can merge. Press New Game to start over.
